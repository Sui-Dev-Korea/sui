이 fixed supply 예시는 total supply 10,000,000,000,000,000,000개 코인을 민트하고 해당 코인을 송신자에게 전송한다. 그런 다음 추가 modification을 방지하기 위해 treasury cap을 dynamic 객체 필드로 lock한다.

Package를 나중에 수정할 수 없도록 더 확실히 보장하려면 upgrade cap을 transfer하지 말고 burn한다.
