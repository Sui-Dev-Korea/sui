`Pool` 공유 객체는 SUI/USDC 시장과 같은 시장을 나타낸다. 해당 `Pool`은 그 고유한 쌍(SUI/USDC)을 나타내는 유일한 객체이며, 그 쌍은 해당 `Pool`의 유일한 member이다. 풀의 구조에 대해 더 알아보려면 [설계](/onchain-finance/deepbookv3/design#pool)을 참조한다.

거래를 수행하려면 관련 `BalanceManager`에 `TradeProof`와 `Pool`를 전달한다. `Pool`과 달리 `BalanceManager` 공유 객체는 어떤 타입의 토큰도 포함할 수 있으므로, 동일한 `BalanceManager`가 여러 `Pool`에 접근하여 다양한 거래 페어링과 상호작용할 수 있다. 더 알아보려면 [BalanceManager](/onchain-finance/deepbookv3/contract-information/balance-manager)를 참조한다.
