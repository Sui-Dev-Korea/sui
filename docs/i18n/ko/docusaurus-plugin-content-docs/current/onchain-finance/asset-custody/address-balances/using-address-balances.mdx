주소 잔액은 Sui 주소에 직접 연결된 각 coin type별 canonical balance를 제공한다. `sui::coin::send_funds`와 `sui::balance::send_funds`를 통해 전송된 funds는 object management 없이 coin type별 단일 balance로 자동 merge된다. 전체 specification은 [SIP-58: Sui Address Balances](https://github.com/sui-foundation/sips/blob/main/sips/sip-58.md)를 참조한다.

## funds 보내기

`send_funds`를 사용해 recipient의 주소 잔액에 직접 deposit한다. recipient balance는 새 object를 만들지 않고 증가하며, 서로 다른 sender의 여러 deposit도 하나의 balance로 모두 merge된다.

### TypeScript SDK

recipient의 주소 잔액에 token을 deposit하려면 coin object를 만드는 대신 `tx.balance()`와 `balance::send_funds`를 사용한다.

```tsx
const tx = new Transaction();

tx.moveCall({
	target: '0x2::balance::send_funds',
	typeArguments: ['0x2::sui::SUI'],
	arguments: [tx.balance({ balance: 1_000_000_000n }), tx.pure.address('0xRecipientAddress')],
});
```

`tx.balance()`와 `send_funds`, `redeem_funds` 같은 eligible Move call만 사용해 빌드한 transaction은 network가 지원할 때 zero gas fee 대상이 될 수 있다.

### CLI

[Sui CLI](/references/cli/ptb)를 사용해 funds를 보내려면:

```bash
# Send from gas coin to address balance
sui client ptb \
    --split-coins gas '[5000000]' \
    --assign coin \
    --move-call 0x2::coin::send_funds '<0x2::sui::SUI>' coin @<RECIPIENT_ADDRESS>

# Send from another coin
sui client ptb \
    --split-coins @<COIN_ID> '[5000000]' \
    --assign coin \
    --move-call 0x2::coin::send_funds '<COIN_TYPE>' coin @<RECIPIENT_ADDRESS>
```

| **Flag** | **설명** |
|----------|----------------|
| `--to` | Recipient address. |
| `--amount` | MIST 단위로 보낼 amount. |
| `--coin-type` | 보낼 coin type. 기본값은 `0x2::sui::SUI`이다. |
| `--all-coins` | 지정된 type의 모든 coin balance를 보낸다. `--stateless`와 함께 사용할 수 없다. |
| `--stateless` | 주소 잔액만 사용해 stateless transaction을 빌드한다(owned object input 없음). replay protection을 위해 `ValidDuring` expiration을 사용한다. |

기본적으로 command는 coin을 먼저 선택하고 coin이 부족하면 주소 잔액으로 fallback한다. `--stateless`를 사용하면 주소 잔액에서만 인출한다.

### Move function

Sui framework는 `balance`와 `coin` module 모두에 `send_funds`를 제공한다.

```move
// Send a Balance<T> to an address balance
public fun send_funds<T>(balance: Balance<T>, recipient: address)

// Send a Coin<T> to an address balance (converts to balance internally)
public fun send_funds<T>(coin: Coin<T>, recipient: address)
```

자세한 내용은 [sui-framework/sources/balance.move](https://github.com/MystenLabs/sui/blob/main/crates/sui-framework/packages/sui-framework/sources/balance.move#L102))와 [sui-framework/sources/coin.move](https://github.com/MystenLabs/sui/blob/main/crates/sui-framework/packages/sui-framework/sources/coin.move#L176)를 참조한다.

## funds 인출

withdrawal input을 만들고 redeem하여 `Coin<T>`를 얻는다.

```tsx
const tx = new Transaction();

const [coin] = tx.moveCall({
	target: '0x2::coin::redeem_funds',
	typeArguments: ['0x2::sui::SUI'],
	arguments: [tx.withdrawal({ amount: 1_000_000_000 })],
});

tx.transferObjects([coin], '0xRecipientAddress');
```

`Balance<T>`를 직접 얻는다.

```tsx
const [balance] = tx.moveCall({
	target: '0x2::balance::redeem_funds',
	typeArguments: ['0x2::sui::SUI'],
	arguments: [tx.withdrawal({ amount: 1_000_000_000 })],
});
```

SUI가 아닌 coin type의 경우 `type` parameter를 전달한다.

```tsx
const [coin] = tx.moveCall({
	target: '0x2::coin::redeem_funds',
	typeArguments: ['0xPackageId::module::USDC'],
	arguments: [tx.withdrawal({ amount: 1_000_000, type: '0xPackageId::module::USDC' })],
});
```

transaction에서 주소 잔액 funds를 사용하려면 이를 withdraw한 뒤 `Coin<T>` 또는 `Balance<T>`로 redeem한다.

### TypeScript SDK

gas나 transaction argument로 coin object를 명시적으로 선택하지 않는다면, TypeScript SDK는 coin object와 주소 잔액을 모두 자동으로 확인하고 올바른 source에서 인출한다.

```typescript
import { Transaction } from '@mysten/sui/transactions';

const tx = new Transaction();
tx.transferObjects([tx.coin({ balance: requiredAmount })], recipient);
```

### TypeScript SDK: manual withdrawals

주소 잔액 withdrawal을 명시적으로 제어하려면 [`tx.withdrawal()`](https://sui-typescript-docs-git-mh-address-balance-docs-mysten-labs.vercel.app/sui/transactions/reference#address-balance-withdrawals)을 사용한다. usable `Coin<T>` 또는 `Balance<T>`를 생성하려면 withdrawal을 `redeem_funds`로 redeem해야 한다.

```typescript
import { Transaction } from '@mysten/sui/transactions';

const tx = new Transaction();

// Withdraw SUI from address balance and redeem to Coin
const [coin] = tx.moveCall({
	target: '0x2::coin::redeem_funds',
	typeArguments: ['0x2::sui::SUI'],
	arguments: [tx.withdrawal({ amount: 1_000_000_000 })], // 1 SUI in MIST
});

// Withdraw a custom coin type
const coinType = '0xPackageId::module::CoinType';
const [customCoin] = tx.moveCall({
	target: '0x2::coin::redeem_funds',
	typeArguments: [coinType],
	arguments: [tx.withdrawal({ amount: 1_000_000, type: coinType })],
});

// Transfer to recipient
tx.transferObjects([coin], recipient);
```

:::info

`tx.withdrawal()`은 coin 또는 balance를 만들기 위해 redeem해야 하는 `Withdrawal<Balance<T>>` capability를 생성한다. 이를 수행하려면 `0x2::coin::redeem_funds()` 또는 `0x2::balance::redeem_funds()`를 사용한다. `coinWithBalance` intent는 이 작업을 자동으로 수행한다.

:::

### Rust SDK: manual withdrawals

Rust에서 주소 잔액에서 withdraw하려면 [`FundsWithdrawalArg`](https://github.com/MystenLabs/sui/blob/main/crates/sui-types/src/transaction.rs)를 사용한다. helper `FundsWithdrawalArg::balance_from_sender(amount, balance_type)`는 편리한 constructor를 제공한다.

```rust
use sui_types::transaction::{FundsWithdrawalArg, WithdrawalTypeArg, Reservation, WithdrawFrom};

let withdrawal_arg = FundsWithdrawalArg {
    reservation: Reservation::MaxAmountU64(amount),
    type_arg: WithdrawalTypeArg::Balance(coin_type),
    withdraw_from: WithdrawFrom::Sender,
};
```

PTB에서 withdrawal input을 다음 중 하나에 전달한다.

- `0x2::balance::redeem_funds<T>()`: `Balance<T>`를 얻는다.
- `0x2::coin::redeem_funds<T>()`: `Coin<T>`를 얻는다.

같은 coin type에 대해서도 PTB에 여러 `FundsWithdrawalArg` input을 넣을 수 있다.

```rust
let mut builder = ProgrammableTransactionBuilder::new();

let withdraw_arg = FundsWithdrawalArg::balance_from_sender(
    withdraw_amount,
    sui_types::gas_coin::GAS::type_tag(),
);
let withdraw_input = builder.funds_withdrawal(withdraw_arg).unwrap();

// Redeem to coin
let coin = builder.programmable_move_call(
    SUI_FRAMEWORK_PACKAGE_ID,
    Identifier::new("coin").unwrap(),
    Identifier::new("redeem_funds").unwrap(),
    vec!["0x2::sui::SUI".parse().unwrap()],
    vec![withdraw_input],
);

builder.transfer_arg(recipient, coin);
```

자세한 내용은 [sui-types/src/programmable_transaction_builder.rs](https://github.com/MystenLabs/sui/blob/main/crates/sui-types/src/programmable_transaction_builder.rs)를 참조한다.

### withdrawal split과 join

PTB 안에서 withdrawal을 split하고 merge할 수 있다.


## 주소 잔액에서 gas 지불

주소 잔액 gas payment에서는 `setGasPayment`에 empty array를 전달한다. coin object version을 lookup할 필요가 없으므로 fully offline transaction building이 가능해진다.

```typescript
const tx = new Transaction();
tx.setGasPayment([]); // Empty array = use address balance for gas
```

Rust에서는 `gas_data.payment`를 empty vector로 설정하고 [`ValidDuring`](https://github.com/MystenLabs/sui/blob/main/crates/sui-types/src/transaction.rs) expiration을 사용한다.

```rust
TransactionData::V1(TransactionDataV1 {
    kind: tx_kind,
    sender,
    gas_data: GasData {
        payment: vec![],  // Empty - gas paid from address balance
        owner: sender,
        price: rgp,
        budget: 10_000_000,
    },
    expiration: TransactionExpiration::ValidDuring {
        min_epoch: Some(current_epoch),
        max_epoch: Some(current_epoch + 1),
        min_timestamp: None,
        max_timestamp: None,
        chain: chain_identifier,
        nonce: unique_nonce,
    },
})
```

주소 잔액 gas payment 요구 사항:

- `gas_data.payment`는 empty여야 한다.
- `expiration`은 `min_epoch`와 `max_epoch`가 모두 지정된 `ValidDuring`이어야 한다.
- `max_epoch`는 최대 `min_epoch + 1`이어야 한다(single epoch 또는 1-epoch range).
- Timestamp-based expiration은 현재 지원되지 않는다.
- transaction kind는 `ProgrammableTransaction`이어야 한다.

`nonce` field는 그 외에는 동일한 transaction을 구분한다. EVM chain과 달리 nonce에는 semantic requirement가 없다. sequential일 필요가 없으며 nonce gap problem도 없다. otherwise same digest를 가질 두 transaction을 제출할 수 있게 한다. 대부분의 use case에서는 nonce를 random하게 생성하거나 application에서 incrementing counter를 사용한다.

```rust
// Random nonce
let nonce: u32 = rand::random();

// Or incrementing counter
let nonce: u32 = self.next_nonce.fetch_add(1, Ordering::SeqCst);
```

주소 잔액 gas payment를 사용하기 전에 protocol configuration flag를 확인해 network에서 feature가 활성화되어 있는지 검증할 수 있다.

## Sponsored transaction

주소 잔액은 coin 기반 sponsorship에 비해 sponsored transaction을 단순화한다.

- gas coin locking risk가 없다.
- sponsor가 gas coin inventory를 관리할 필요가 없다.
- user가 sponsor보다 먼저 sign할 수 있으므로 더 단순한 async flow가 가능하다.
- permissionless public gas station을 가능하게 한다.

:::caution
여기서도 `GasCoin` argument는 여전히 유효하며, 주소 잔액 gas payment를 사용하더라도 sponsored transaction에서 사용 여부를 계속 monitor해야 한다.
:::

주소 잔액에서는 user가 먼저 sign하고 sponsor가 나중에 sign한다.

```typescript
// 1. User builds and signs the transaction first
const tx = new Transaction();
tx.setSender(userAddress);
tx.setGasOwner(sponsorAddress);
tx.setGasPayment([]); // Empty array = sponsor pays from address balance
// ... add commands ...

const bytes = await tx.build({ client });
const { signature: userSignature } = await userKeypair.signTransaction(bytes);

// Option A: Send transaction and signature to sponsor, sponsor can sign and execute immediately:
// (`send_tx_to_sponsor` is a placeholder, there is no such API in the SDK)
await send_tx_to_sponsor(userSignature, bytes);

// Option B: Get signature from sponsor and submit it ourselves. Sponsor signs (can happen asynchronously)
const { signature: sponsorSignature } = await sponsorKeypair.signTransaction(bytes);

const result = await client.executeTransaction({
	transaction: bytes,
	signatures: [userSignature, sponsorSignature],
});
```

sender와 sponsor는 모두 sign해야 한다. Storage rebate는 sponsor 주소 잔액에 credit된다.

## 잔액 쿼리

TypeScript SDK, gRPC 또는 GraphQL을 사용해 주소 잔액을 쿼리할 수 있다.

### TypeScript SDK

coin object와 주소 잔액을 모두 보려면 `getBalance`를 사용한다.

```tsx
const { balance } = await grpcClient.getBalance({
	owner: '0xMyAddress',
});

console.log(balance.balance); // total balance as string (coin objects + address balance)
console.log(balance.coinBalance); // balance from coin objects only
console.log(balance.addressBalance); // balance from address balance only
console.log(balance.coinType); // e.g. "0x2::sui::SUI"
```

모든 balance value는 string으로 반환된다. numeric type에는 `BigInt(balance.balance)`를 사용한다.

### gRPC

`StateService`의 [`GetBalance`](/references/fullnode-protocol#sui-rpc-v2-GetBalanceRequest)와 [`ListBalances`](/references/fullnode-protocol#sui-rpc-v2-ListBalancesRequest)를 사용한다.

```bash
buf curl --protocol grpc https://fullnode.testnet.sui.io/sui.rpc.v2.StateService/GetBalance \
    -d '{
        "owner": "<ADDRESS>",
        "coin_type": "0x2::sui::SUI"

# List all balances
buf curl --protocol grpc https://fullnode.testnet.sui.io/sui.rpc.v2.StateService/ListBalances \

```

## checkpoint data에서 balance changes 계산

주소 잔액을 사용할 때 balance changes를 계산하려면 `TransactionEffects`의 accumulator event도 처리해야 한다.

```rust
use sui_types::balance_change::{derive_balance_changes, BalanceChange};

let balance_changes: Vec<BalanceChange> = derive_balance_changes(
    &effects,
    &input_objects,
    &output_objects,
);
```

algorithm:

1. **input coin 차감:** 각 input coin object에 대해 `(owner, coin_type)`에서 value를 차감한다.
2. **output coin 추가:** 각 mutated 또는 created coin object에 대해 `(owner, coin_type)`에 value를 추가한다.
3. **accumulator event 처리:** `Balance<T>` type을 가진 각 accumulator event에 대해:
   - `Split` operation: amount를 차감한다(address balance에서 funds withdrawn).
   - `Merge` operation: amount를 추가한다(address balance에 funds deposited).

전체 algorithm은 [reference implementation](https://github.com/MystenLabs/sui/blob/e23cc4bb0215ec065785a19772f22eda8ada14ae/crates/sui-types/src/balance_change.rs#L86)을 참조한다.

### accumulator event 접근

Accumulator event는 [`TransactionEffects`](https://github.com/MystenLabs/sui/blob/main/crates/sui-types/src/effects/mod.rs)에 embedded되어 있다.

```rust
use sui_types::effects::TransactionEffectsAPI;

let events = effects.accumulator_events();
for event in events {
    let address = event.write.address.address;
    let balance_type = &event.write.address.ty;

    // Only Balance<T> types represent balance changes
    if let Some(coin_type) = Balance::maybe_get_balance_type_param(balance_type) {
        let amount = match &event.write.value {
            AccumulatorValue::Integer(v) => *v as i128,
            _ => continue,
        };

        let signed_amount = match event.write.operation {
            AccumulatorOperation::Split => -amount,  // Withdrawal
            AccumulatorOperation::Merge => amount,   // Deposit
        };

        // (address, coin_type, signed_amount) represents the balance change
    }
}
```

[`BalanceChange`](https://github.com/MystenLabs/sui/blob/main/crates/sui-types/src/balance_change.rs) struct는 결과를 나타낸다.

```rust
pub struct BalanceChange {
    pub address: SuiAddress,
    pub coin_type: TypeTag,
    pub amount: i128,  // Negative = spent, positive = received
}
```

## 기존 coin을 주소 잔액으로 변환

Migration은 선택 사항이다. [Sui CLI](/references/cli/ptb)를 사용해 coin을 주소 잔액으로 consolidate하려면:

```bash
sui client ptb \
    --merge-coins @<COIN_1> '[@<COIN_2>, @<COIN_3>]' \
    --move-call 0x2::coin::send_funds '<0x2::sui::SUI>' @<COIN_1> @<YOUR_ADDRESS>
```

SUI coin의 경우 gas로 smash한 뒤 `--move-call 0x2::coin::send_funds --gas-coin <COIN>`을 사용할 수 있다.

TypeScript SDK는 필요에 따라 coin 또는 주소 잔액을 자동으로 선택한다. `Coin<T>` 또는 `Balance<T>`를 받는 contract는 계속 호출할 수 있다. `redeem_funds` function은 PTB 안에서 withdrawal을 expected type으로 변환한다.

TypeScript SDK 사용:

```typescript
import { Transaction } from '@mysten/sui/transactions';

const tx = new Transaction();
tx.moveCall({
    target: '0x2::coin::send_funds',
    typeArguments: ['0x2::sui::SUI'],
    arguments: [tx.coin({ balance: totalAmount }), tx.pure.address(yourAddress)],
});
```

이는 삭제된 coin object에서 storage rebate를 얻을 수 있다.
