`MarginManager`는 `BalanceManager`를 감싸며 예치, 출금, trade, 그리고 leveraged 포지션을 관리하는 데 필요한 capability를 제공하는 공유 객체이다. 이는 사용자가 마진 풀에서 자산을 차입하여 trading 포지션을 확대할 수 있게 하면서, collateralization을 통해 risk를 관리하도록 한다.

각 `MarginManager`는 특정 DeepBook 풀과 연관되며, 해당 풀에서 trading을 허용하는 마진 풀로부터 차입할 수 있다. margin manager는 차입 포지션을 추적하고 시스템 건전성을 유지하기 위해 risk ratio limit을 강제한다.
