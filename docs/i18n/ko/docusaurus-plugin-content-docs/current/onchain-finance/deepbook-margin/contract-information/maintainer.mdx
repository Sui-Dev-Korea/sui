maintainer 모듈은 마진 풀을 관리하고, 금리를 구성하고, 어떤 DeepBook 풀이 margin lending에 접근할 수 있는지 제어하는 함수를 제공한다. 이 함수들은 적절한 capability를 가진 maintainer로 제한된다.

## API

다음은 `MarginPool`이 제공하는 maintainer 함수가다.

<details>
<summary>Create a 마진 풀</summary>

특정 자산에 대한 새로운 마진 풀을 생성하고 등록한다. 자산 type당 하나의 마진 풀만 존재할 수 있다.

<ImportContent
	source="packages/deepbook_margin/sources/margin_pool.move"
	mode="code"
	org="MystenLabs"
	repo="deepbookv3"
	fun="create_margin_pool"
	noComments
/>

</details>

<details>
<summary>Enable or disable DeepBook 풀</summary>

이 마진 풀에서 차입할 수 있는 DeepBook 풀을 제어한다. 활성화된 풀과 연결된 margin manager만 대출을 받을 수 있다.

<ImportContent
	source="packages/deepbook_margin/sources/margin_pool.move"
	mode="code"
	org="MystenLabs"
	repo="deepbookv3"
	fun="enable_deepbook_pool_for_loan,disable_deepbook_pool_for_loan"
/>

</details>

<details>
<summary>Update 풀 파라미터</summary>

금리 파라미터와 마진 풀 configuration setting을 업데이트한다.

<ImportContent
	source="packages/deepbook_margin/sources/margin_pool.move"
	mode="code"
	org="MystenLabs"
	repo="deepbookv3"
	fun="update_interest_params,update_margin_pool_config"
/>

</details>

<details>
<summary>Withdraw fees</summary>

마진 풀에서 누적된 maintainer 및 프로토콜 수수료를 인출한다.

<ImportContent
	source="packages/deepbook_margin/sources/margin_pool.move"
	mode="code"
	org="MystenLabs"
	repo="deepbookv3"
	fun="withdraw_maintainer_fees,withdraw_protocol_fees,admin_withdraw_default_referral_fees"
/>

</details>
