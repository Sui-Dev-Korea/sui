Legacy Rust SDK 크레이트는 Sui 저장소의 [`crates/sui-sdk` directory](https://github.com/MystenLabs/sui/tree/main/crates/sui-sdk)에 있다.

이 SDK는 [`sui-rust-sdk`](https://github.com/MystenLabs/sui-rust-sdk)와 순방향 및 역방향 호환되며 JSON RPC를 지원한다. JSON RPC가 필요하지 않다면 대신 [`sui-rust-sdk`](https://github.com/MystenLabs/sui-rust-sdk)를 사용한다.
