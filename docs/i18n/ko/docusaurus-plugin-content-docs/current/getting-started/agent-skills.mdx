Sui 빌드용 재사용 가능한 에이전트 스킬이다. `skills` CLI로 Claude Code, Cursor, Codex와 40개 이상의 다른 AI 코딩 에이전트에 설치한다.

사용 가능한 스킬 목록을 확인한다:

```sh
npx skills add mystenlabs/skills --list
```

모든 스킬을 설치한다:

```sh
npx skills add mystenlabs/skills --all
```

특정 스킬을 설치한다:

```sh
npx skills add mystenlabs/skills --skill move
```
