Sui는 탈중앙화 애플리케이션을 빌드하는 데 적합한 네이티브 프리미티브 전체 스택을 갖춘 확장 가능하고 성능이 뛰어난 레이어 1 블록체인이다.

[암호화](https://seal-docs.wal.app/UsingSeal/), [데이터 스토리지](https://docs.wal.app/usage/setup), 검증, 접근 제어를 위한 프리미티브는 개발자에게 레이어 2 체인이나 오프체인 솔루션을 사용할 필요 없이 애플리케이션 스택의 모든 요소를 제공한다.

다른 체인과 달리 Sui는 네트워크의 모든 항목이 객체인 [객체 중심 모델](/develop/sui-architecture/object-model)을 사용한다.

[트랜잭션](/develop/transactions/txn-overview)은 객체를 입력으로 사용하며, 기존 객체를 변경하거나 새 객체를 만든다.

각 객체는 고유한 온체인 ID를 가진다.

객체를 만들고, 트랜잭션을 제출하고, Sui에서 애플리케이션 빌드를 시작하려면 먼저 Sui를 설치해야 한다.

이 설치에는 주소 잔액을 생성하고 관리하고, 스마트 계약을 빌드하고 게시하고, 네트워크에서 정보를 조회하는 도구인 [Sui CLI](/references/cli)가 포함된다.

## 빠른 설치

Sui CLI는 Sui 네트워크와 상호작용하고, 패키지를 배포하고, 자산을 관리하는 데 사용된다.

Sui CLI를 설치하려면 [`suiup`](https://github.com/MystenLabs/suiup)을 사용할 수 있다.

[`suiup`](https://github.com/MystenLabs/suiup)은 Sui CLI뿐 아니라 [`walrus`](https://docs.wal.app/usage/setup)와 [`mvr`](https://github.com/MystenLabs/mvr) 같은 다른 Sui 스택 구성 요소의 서로 다른 버전도 쉽게 설치하고 전환할 수 있게 하므로 가장 효과적인 설치 방법이다.

[Homebrew](https://brew.sh/) 또는 [Chocolately](https://chocolatey.org/)를 사용하는 대체 빠른 설치 지침은 다른 Sui 스택 구성 요소 설치를 지원하지 않는다.

나중에 이를 사용하고 싶다면 다른 구성 요소는 각자의 바이너리로 개별 설치해야 한다.

:::caution

Homebrew 또는 Chocolatey를 사용하는 설치는 [Sui 사전 요구 사항](/getting-started/onboarding/install-source)을 아무것도 설치하지 않은 경우 몇 분이 걸릴 수 있다.

`suiup`을 사용하는 방법이 대개 훨씬 빠르며 적극 권장된다.

:::

## 설치 세부 정보

### `suiup` 설치 세부 정보

설치 파일과 그 위치에 관한 정보는 `suiup` 리포지터리의 [README](https://github.com/mystenLabs/suiup?tab=readme-ov-file#paths-used-by-the-suiup-tool)를 참조한다.


### 기본 구성 파일

`suiup`, Homebrew, Chocolately 중 어느 것을 사용했는지와 관계없이 Sui는 기본 구성을 `~/.sui/sui_config/client.yaml` 파일에 저장한다.

이 파일은 다음과 같은 환경 설정과 기본값을 정의한다:

- Mainnet, Testnet, Devnet, Localnet 네트워크 환경 세부 정보.

- 활성 환경으로, CLI 명령이 대상으로 삼을 네트워크를 지정한다.

- 활성 주소로, CLI가 트랜잭션과 쿼리에 사용할 Sui 주소를 지정한다.

- keystore 위치로, Sui가 주소의 개인 키를 저장하는 위치를 지정한다.
