Chain-specific gas fee는 end user에게 여러 friction point를 만들고 asset trading 또는 payment의 institutional compliance에 복잡성을 더할 수 있다. Chain-specific gas를 제거하면 regulated institution은 가치가 계속 변동할 수 있는 digital asset을 보유해야 하는 부담 없이 payment를 수행할 수 있으므로 크게 단순화된다.

Sui의 gasless transaction은 적격 stablecoin의 peer-to-peer payment를 SUI gas fee 없이 실행할 수 있게 한다. Transaction sender는 wallet에 SUI를 보유할 필요가 없다. 다만 network가 congestion 상태일 때는 gas fee를 지불하는 transaction이 gasless transaction보다 우선 처리된다.

Gasless transaction에 적격인 stablecoin은 다음과 같다:

- USDC

- Sui Dollar(출시 예정)

- eSui Dollar (SuiUSDe)

- USDY (Ondo)

- FdUSD (First Digital)

- AUSD (Agora)

- BUCK (Bucket Protocol)

- YLSD (Figure)

- USDT(출시 예정)

## Gasless transaction 지원

Sui gasless transaction은 [Address Balances](/onchain-finance/asset-custody/address-balance-migration) 기능의 extension이며, Address Balances Move API `send_funds()`를 `gas=0` 및 `gas_budget=0`으로 호출해 활성화된다.

Gasless transaction은 Move function `withdrawal_split`, `redeem_funds`, `send_funds`로 제한된다. Gasless transaction은 어떤 object도 write하는 데 사용할 수 없다.
