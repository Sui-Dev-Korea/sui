장기적인 과거 온체인 데이터 접근은 개발자에게 필수적이지만, 풀 노드는 확장성과 성능을 위해 제한된 리텐션만 강제한다. 아카이브 스토어 및 서비스는 풀 노드나 인덱서 데이터베이스가 일반적으로 보관하는 범위를 넘어 Sui의 과거 데이터에 접근하기 위한 확장 가능하고 일관된 기반을 제공한다. 이 인프라는 GraphQL RPC, gRPC 기반 앱, 데이터 플랫폼의 과거 데이터 기반 역할을 하며, 풀 노드가 데이터를 정리한 뒤에도 오래된 트랜잭션, 체크포인트, 객체 상태를 효율적으로 포인트 조회할 수 있게 한다.
