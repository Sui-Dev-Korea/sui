gRPC는 빠르고 compact한 데이터 직렬화를 위해 [Protocol Buffers](https://protobuf.dev/overview/)를 사용하는 고성능의 효율적인 통신 프로토콜이다. 강하게 타입화된 인터페이스는 런타임 오류를 줄이고 여러 언어에서 클라이언트와 서버 개발을 단순화한다.

[Sui 풀 노드 gRPC API](/references/fullnode-protocol)는 Sui 블록체인과 상호작용하기 위한 빠르고 타입 안전하며 효율적인 인터페이스를 제공한다. 파워 유저, 인덱서, 익스플로러, 탈중앙화 앱을 위해 설계된 이 API는 높은 성능과 낮은 지연 시간으로 Sui 데이터에 접근할 수 있게 한다.
